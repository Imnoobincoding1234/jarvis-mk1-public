# Jarvis Search

Launch `Jarvis Search.app`, then press `Command + 9` to open the Jarvis-themed search overlay.

Controls:

- Type to search apps, files, and folders using macOS Spotlight.
- Use Up/Down to move through results.
- Press Enter to open the selected result.
- Press Escape to close the overlay.
- Use the `J` menu-bar item to quit the helper.

Notes:

- If macOS blocks the app the first time, open System Settings > Privacy & Security and allow it.
- The app uses a local ad-hoc signature and does not send searches anywhere.
- The source and rebuild script are in `work/JarvisSearch`.
